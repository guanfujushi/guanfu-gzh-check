# 公众号排版体检官 · gzh-layout-check

> 文稿粘进公众号后台之前，先花 3 秒做个体检——12 类排版硬伤一次报全，连修法一起给你。

**作者：观复居士 ·商务合作：13148728713；微信号：guanfujs**

## 为什么做这个

写完一篇稿子，最怕的不是写得不好，是**发出去才发现排版散架**：段落一坨、图注带编号、中文里混着半角逗号、AI 标识贴在第一行。

人眼审稿会漏，尤其是第 30 遍看自己的稿子时。这个工具把「能机器查的」全查掉，你只管判断内容。

## 能查什么

| # | 检查项 | 级别 | 说人话 |
|---|---|---|---|
| 1 | 文首 AI 标识 | 🔴 阻塞 | 第一屏贴 AI 标签，读者立刻划走 |
| 2 | 图注编号「图 1」 | 🟠 警告 | 编号是内部稿痕迹，不是给读者看的 |
| 3 | 标题层级跳级 | 🟠 警告 | `##` 直接跳 `####`，结构断掉 |
| 4 | 超长段落 >200 字 | 🟠 警告 | 手机一屏挤成黑块 |
| 5 | 中文夹半角标点 | 🟠 警告 | 「没校对」的第一眼证据 |
| 6 | 品牌标签重复 | 🟠 警告 | 重复不是强调，是刷屏 |
| 7 | 中英混排未加空格 | 🔵 提示 | 加了空格，观感上一个档 |
| 8 | 连续空行 | 🔵 提示 | 后台吃空行，样式忽宽忽窄 |
| 9 | 全角/行尾空格 | 🔵 提示 | 手机上宽度不可控 |
| 10 | 图片缺 alt | 🔵 提示 | 图挂了不至于全白 |
| 11 | 裸露长链接 | 🔵 提示 | 折成三行很难看 |
| 12 | 字数与阅读时长 | ℹ️ 信息 | 400 字/分钟估算 |

## 装

零依赖，只要 Python 3.8+。把仓库拉下来即可：

```bash
git clone https://github.com/guanfujushi/guanfu-gzh-check.git
```

如果你用 AI 助手（支持 Skill 的客户端），把整个目录放进 skills 目录，
它会自己读 `SKILL.md` 并按需调用脚本。

## 用

```bash
python3 scripts/check_layout.py 你的文稿.md
python3 scripts/check_layout.py 排好的稿子.html --tag "你的品牌名"
python3 scripts/check_layout.py 文稿.md --json    # 给脚本串联用
```

退出码：`0` 全过 ｜ `1` 有警告 ｜ `2` 有阻塞项——可以直接接进 CI。

## 输出长这样

```
════ 公众号排版体检报告 ════
文件：定稿.md      体检分：67 / 100

【阻塞】1 项
  ① 文首 AI 标识 —— 开头 400 字内出现 AI 生成声明
     修法：删掉该行；AI 标识只留文末一处

【警告】3 项
  ① 图注编号 —— 出现「图 1：」
     修法：改成叙事性图注，一句话说画面里发生了什么
  ② 标题层级跳级 —— 从 H2 直接跳到 H4
  ③ 半角标点 —— 3 处中文里用了半角标点

【信息】正文字数 282 字 ｜ 预估阅读 1 分 ｜ 段落 10 段
════════════════════════
```

## 它不做什么

- **不改你的字**：只报问题，改不改你定
- **不联网**：不调模型、不上传任何内容
- **不做内容审核**：事实、观点、合规——这些归人管
